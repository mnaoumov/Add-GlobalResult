# Add-GlobalResult
A helper which adds PowerShell's auto variable $Global:LastResult

This an extended version which works in all cases: it captures arrays, returns immediately and works with Format-* cmdlets

## Filing an issue (for AI agents and humans)

Open issues through the [issue forms](https://github.com/mnaoumov/Add-GlobalResult/issues/new/choose), not as blank issues.

Filing from the CLI or the API (`gh issue create --body`, or an AI agent filing for you) skips the form, and `gh issue create --template` cannot load an issue form. In that case, open the matching form in [`.github/ISSUE_TEMPLATE/`](https://github.com/mnaoumov/Add-GlobalResult/tree/HEAD/.github/ISSUE_TEMPLATE), copy every field as a `### <label>` heading in the form's order, and fill in each one. Always state the version you used and your operating system.
